# Export notes

This bounded export contains 23 journal-linked reports and 43 supporting authored reports, scientific summaries, tables and prototype/audit source files. It does not include downloaded papers, the private manuscript, conversation transcripts, full external repositories or complete historical campaign directories.

The [export manifest](EXPORT_MANIFEST.json) records the original and exported SHA-256 for every included file. Byte-identical scientific summaries and Python sources are identified explicitly. Report edits only make paths portable, label omitted links and remove private environment/document locations. The capacity validation JSON has one descriptive top-level campaign path made research-relative; all other values and scientific identity hashes are retained. These publication views do not replace the immutable source records.

The current [prototype](adaptive_prototype_20260921/README.md) includes its model, demo, tests and saved results. The [gate audit](research_refresh_20260921/GATE_AUDIT.md) includes its small audit JSON and verification scripts; reproducing its historical checks additionally requires original campaign inputs that are outside this bounded export.
